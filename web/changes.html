What changes with piterfly?

A SLOOP 2.8.5 variant for the M-VAVE FM-1, with more room for patterns and a clearer view of long sequences. The same four tracks and up to 64 steps per track.

  • 24 stored patterns instead of 4. Six banks, A1–F4, each storing a complete four-track loop.
  • 128 song positions instead of 16. Arrange patterns in order, with 1–64 bars per position.
  • Clearer controls. Full step overviews, track-coloured selection frames that turn red during recording, page-navigation dots and save/delete icons.
  • Control external instruments with MIDI THRU. Forward incoming notes per track; turn its internal volume down to play only your external synth. See the channel 1 setup.
  • Explicit save status. PENDING means waiting for flash; SAVED confirms completion. Failed settings writes are retried, and song files are checked before import starts.

See where you are in the options

Compact page indicators beside the BPM show how many pages are available and which one you are on. They follow your colour theme, with a contrasting active dot, and disappear when a section has only one page.

Both illustrations use the same notes, 64-step track and playback step 39 with the green theme. The legacy view is a schematic reconstruction with current GPL icons. GLO now has 10 pages, including MIDI THRU.

On HOME, FX and other parameter pages, PRESETS selects the track and ALGORITHM browses its sounds or drum kits. You can change the source sound while keeping GRANUL, including FREEZE. The active NOTES editor keeps its existing pair: PRESETS zooms, ALGORITHM selects the track. SONG, system settings and held-button controls keep their assignments; track selection stays locked during a free take.

Play an external synth with MIDI THRU

Play a note into the FM-1 and pass it on to an external synth. Turn THRU on for the tracks you need; each sends the received notes and velocity on its assigned MIDI channel.

Using a Mac and MidiPipe? Follow the FM-1 + Behringer D MINI setup guide for the exact MyPipe tool order, USB and audio wiring, channel assignments and the difference between sequencer output and live keyboard THRU.

Actual firmware UI renders, rather than hardware photos. THRU and channel assignments survive power-off and pattern changes; LEVEL belongs to each pattern. Keep track 1’s LEVEL at zero in the patterns used for this setup. THRU forwards Note On/Off and velocity; CC, sustain and pitch bend are not forwarded. The FM-1’s TRS jack is an input; forwarded MIDI leaves over USB.

Live granular processing · experimental

Turn any track into a granular texture, including FM and drum synth sounds. Select GRANUL on the existing INSERT page: knob 1 selects the effect, knob 2 selects a parameter pair, and knobs 3–4 edit its values. SELECT navigates between FX pages normally. FREEZE holds a fragment and keeps the cloud playing after the original notes end.

Changing a sound or engine keeps an active GRANUL insert and its settings. FREEZE preserves the captured audio; LIVE captures the new sound. Parameter edits update only changed fields, without blanking the screen.

The shared memory provides about 3.34 seconds for one granular track, 1.67 seconds each for two, 1.11 for three, or 0.84 for four. The other tracks and existing effects remain available. Capture is mono at 22.05 kHz using lossy 8-bit µ-law; dry audio retains its original quality. Four grains per track bound processing work. This development build still needs timing and listening tests on a physical FM-1.

The trade-off: three user sample banks instead of four. USR4’s 80 KiB is reused for pattern storage. USR1–USR3, factory samples and SYN1–SYN4 remain available.

Back up before installing. Existing A–D patterns migrate to A1–A4, but USR4 is repurposed. Song-file import replaces all 24 pattern slots and the working loop, including empty slots.

Software tests cover storage, migration, playback, UI and the web editor. This version has not yet been validated on a physical FM-1; screen readability and real power-cut behaviour remain to be checked.
