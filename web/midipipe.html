FM-1 + D MINI with MidiPipe

One USB keyboard, four FM-1 tracks and an external Behringer D MINI. The Mac routes MIDI; D MINI plays track 1, while tracks 2–4 use the FM-1’s internal sounds.

This guide reconstructs the user’s working MidiPipe setup. The confirmed SLOOP behaviour, the current piterfly THRU extension and an optional direct-keyboard route are described separately below.

3. Put these four tools in one MyPipe

Keep both connections in the same MyPipe. In the right-hand Pipes column, arrange the tools from top to bottom as shown.

MyPipe

Select each tool and choose its MIDI Input or MIDI Output port.

    Pass Through: OFF

  1. Select the first MIDI In. Set MIDI Input to your external keyboard.
  2. Select the first MIDI Out. Set MIDI Output to Felucca and turn Pass Through OFF. Keyboard messages are delivered to FM-1 and stop continuing through that part of MyPipe.
  3. Select the second MIDI In. Set MIDI Input to Felucca; this receives messages that FM-1 actually sends.
  4. Select the second MIDI Out. Set MIDI Output to D MINI.
  5. Remove redundant Channel Router and Channel Filter tools from this main setup. The channels stay 1→1, 2→2, 3→3, 10→10.
  6. Use File → Save and keep MidiPipe running while using the setup.

Two different “through” settings: MidiPipe’s Pass Through OFF stops a message continuing to later tools after the first MIDI Out. The piterfly GLO → MIDI THRU switch controls whether FM-1 sends received notes back out. These settings do different jobs.

Choose the instrument by changing the keyboard’s transmit channel. Selecting a different track on the FM-1 screen does not change the external keyboard’s channel. This recipe uses IN = NOTES, with fixed track assignments.

On D MINI: set its MIDI receive channel to 1 only, connect its audio output to your listening setup, and confirm it ignores channels 2, 3 and 10. MidiPipe can then send all FM-1 output channels to it without a channel filter in the main pipe.

MidiPipe routes the messages FM-1 actually sends. Routing all its output channels to D MINI does not itself make the tested stock SLOOP resend incoming keyboard notes.

6. Live keyboard with piterfly MIDI THRU

The current piterfly firmware adds per-track forwarding for the channel assignments above. With that build installed, turn TRK1 ON on GLO → MIDI THRU to send received track 1 notes back to USB MIDI OUT. The second MidiPipe input then receives them and sends them to D MINI.

Keyboard ch 1 → FM-1 track 1 → MidiPipe → D MINI ch 1.

Keep CH1 = 1 and IN = NOTES. The current per-track THRU works with this fixed map; this recipe does not use channel 4 or selected-track input mode.

THRU forwards Note On/Off and velocity. CC, sustain and pitch bend are not forwarded. The original confirmation table is not a hardware test of this extension.

Optional: a direct keyboard path for stock SLOOP

Proposed alternative, not a confirmed part of the original setup. Add a separate pipe for live playing on D MINI:

Keyboard→Channel 1 only→D MINI

Use MIDI In: keyboard → Channel Filter: allow only channel 1 → MIDI Out: D MINI. Test that channel 1 reaches D MINI and channels 2, 3 and 10 do not. Keep the existing keyboard → FM-1 route and FM-1 → D MINI sequencer route.

Use one live-note path at a time: this direct route or piterfly’s track 1 THRU. Enabling both can send each keyboard note to D MINI twice.
